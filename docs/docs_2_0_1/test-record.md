# OblivoneSort 2.0.1 测试记录

## 1. 环境与方法

- 编译器：GCC 15.2（MinGW，`-O2`，`-std=c++20`）
- 平台：Windows 11，Intel i5-13500H
- 数据：`double`，13 种模式，固定 seed：

```text
random / sorted / reverse / organ / sawtooth / runs / equal / few
near 0.1% / near 1% / near 5% / push front / push back
```

- 规模与线程：1e6（串行 1 线程；并行 4 线程）、1e7（串行 1 线程；并行 12 线程）；另做 1e8 大规模与特殊数据测试
- 方法：每组合重复 3 次取中位数；算法执行顺序按模式/重复轮转；每次运行后校验有序；1e7 及以下逐元素校验多集等价
- 对比算法：

```text
串行  OblivoneSort、std::sort、std::stable_sort、Boost pdqsort、
      Boost spreadsort、cpp-TimSort
并行  OblivoneSort simple、OblivoneSort advanced、Boost block_indirect_sort、
      Boost sample_sort、Boost parallel_stable_sort
```

Boost 与 cpp-TimSort 仅作为测试依赖，不进入运行时依赖。

表中 `best/O` = 同组最强对手耗时 / Oblivone 耗时；大于 1 表示 Oblivone 更快，小于 1 表示对手更快。

## 6. 结论

- 串行 1e7：random 相对最强对手为 **2.35×**、runs **1.66×**、near 5% **1.28×**、reverse **1.03×**；其余模式落后，其中 organ、push front、push back 相对 TimSort 为 0.15–0.19（TimSort 快约 5–8 倍），sorted / equal 相对 spreadsort 为 0.52–0.57。
- 并行 1e7：random **2.58×**、runs **1.85×**、few **1.47×**、sawtooth **1.31×**、near 5% **1.30×**；organ、push front、push back 相对 boost_sample 为 0.47–0.50。
- 1e8 随机串行 2982 ms（std::sort 10919 ms）；1e8 随机并行 12 线程 641.9 ms（boost_sample 1500.5 ms）。
- 小规模 n ≤ 32 快于 std::sort；n = 64 起 std::sort 占优。
- 所有特殊数据与退化配置正确性通过；`max_buckets < coarse_buckets` 的边界配置不再出现异常退化。
